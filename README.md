# StreamBridge Android

## التطبيق الرسمي

StreamBridge Android هو تطبيق ربط USB وRTSP وHLS مع التخزين المحلي والبث إلى Jaco.

### تنزيل التطبيق

[فتح صفحة التطبيق والتنزيل](https://github.com/alsymymhmd402-jpg/streambridge-downloads/tree/main)

من الصفحة اختر الملف:

`StreamBridge-Android-v0.4.10.apk`

ثم اضغط زر **Download raw file**.
